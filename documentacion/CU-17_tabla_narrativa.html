CU-17 — Destacar Ingreso Fijo

Módulo de Gestión de Movimientos · Sistema de Balance Financiero

Flujo Principal
Paso ACTOR SISTEMA
Paso 1 Durante la creación de un nuevo movimiento de tipo "Ingreso" (por ejemplo, registrar su salario), el usuario localiza la casilla de verificación opcional "🔁 Registrar como Ingreso Constante (Mensual)".
Paso 2 El usuario marca la casilla y procede a guardar el movimiento de manera normal.
Paso 3 El sistema procesa la creación en la base de datos inyectando internamente la propiedad de constancia (esRecurrente: true) a este registro particular.
Paso 4 El usuario retorna a la pantalla de Panel de Control (Dashboard) para observar su tablero.
Paso 5 Al cargar el Dashboard, el sistema ejecuta una evaluación filtrando todo el historial en búsqueda exclusiva de los ingresos que cuenten con la etiqueta de "Recurrente".
Paso 6 El sistema despliega un bloque visual lateral titulado "🔁 Ingresos Constantes". Dentro de este widget, el sistema lista de forma resumida, elegante y persistente el movimiento recién marcado (mostrando su nombre, fecha y monto) para que el usuario pueda tener un monitoreo fijo de sus ganancias garantizadas.
Excepción 1: Revocación de Constancia (Retirar Ingreso Fijo)
Paso ACTOR SISTEMA
E1 - Paso 1 Tiempo después, el ingreso en cuestión deja de ser regular. El usuario, desde su Dashboard, se dirige al panel lateral de "Ingresos Constantes", ubica el registro y hace clic en el botón rojo de remover (✕).
E1 - Paso 2 El sistema captura la acción y lanza de manera transparente una actualización directa (un PATCH) hacia el servidor.
E1 - Paso 3 La base de datos actualiza dicho movimiento y modifica su propiedad "esRecurrente" de verdadera a falsa (falso).
E1 - Paso 4 Al completarse la transacción, el sistema remueve visualmente el ítem del widget lateral. El movimiento original permanece intacto en los listados generales del historial sin borrarse, habiendo perdido únicamente su atributo de "destacado".
